# OneTake documentation

OneTake turns a short script into a polished product demo video. A human-looking cursor
drives your real UI, the camera glides in on what matters, hand-drawn highlights and
captions guide the viewer, and the recorder renders every frame at 60 fps. Write the tour
once and you get the same video on every take.
